# TRY TO EXPLORE ARMENIA

Consent-based location-sharing Flask app.

## Run
1. `pip install -r requirements.txt`
2. Set `ADMIN_USERNAME`, `ADMIN_PASSWORD`, and `FLASK_SECRET_KEY`.
3. `python app.py`
4. Open `/login`.

The two supplied MP4 files are already placed in `static/media/`:
- video_armenia.mp4
- video_yerevan.mp4

Use HTTPS in deployment because browser geolocation requires a secure context.
